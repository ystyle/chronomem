# Web UI 评审与修复（2026-10-15）

> 范围：忆时塔 Web 控制台（6 个页面 + 全部 EP 组件）。
> 方法：**隔离实例实测**（独立数据目录 + 独立端口 18901，不读写生产 8900），
> 灌入 5 个类型 / 175 条测试条目（多粒度、多分组、超长文本、空类型），
> 逐页截图 + 计算样式断言定位根因，修复后复跑同一套断言。

## 复现方式

```bash
# 1) 起隔离实例（独立数据目录 + 端口 18901，不碰生产 8900）
CHRONOLOG_ADDR=0.0.0.0 ./docs/ui/scripts/serve-testenv.sh   # 绑所有网卡以便局域网查看

# 2) 灌测试数据（另开终端；硬拒生产 8900/8901 与 bench 18900）
python3 docs/ui/scripts/seed_testdata.py

# 3) 逐页截图 + 计算样式断言
BASE=http://127.0.0.1:18901 ./docs/ui/scripts/audit.sh
BASE=http://127.0.0.1:18901 bash docs/ui/scripts/audit-overflow.sh
bash docs/ui/scripts/diag-dropdown.sh
```

脚本清单：`serve-testenv.sh`（隔离实例）、`seed_testdata.py`（测试数据）、
`audit.sh`（逐页截图 + 下拉深色断言）、`audit-overflow.sh`（内容裁切自检）、
`diag-dropdown.sh`（下拉深色根因逐层诊断）。

## 一、修复清单

| # | 问题 | 表现 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | **下拉面板白底**（客户点名） | 深色主题下类型下拉是白底，选项文字（浅色）几乎不可读 | 上游 element-plus 内嵌样式里 `.el-select__popper.el-popper`（0-2-0）有**两条**同特异性规则，后一条硬编码 `background:#fff`，压过前面的 `var(--el-bg-color-overlay)`；本仓只写了 `.el-popper`（**0-1-0**）命中不了。**第二层**：`ui.css` 与 cjxt 打包 CSS 加载顺序在后，同特异性下仍被 `#fff` 压回 | 以 `body` 前缀把特异性提到 0-2-1，同时覆盖 arrow 描边与分组标题（见 `ui.css`「EP 弹层深色修正」段） |
| 2 | **下拉选项文字被切成单字母** | 回想页下拉宽度塌成 100px，`worklog` 显示成 `w…` | 上游 popper 用 `left:0;right:0` 撑满触发元素，触发元素窄（102px）时 `text-overflow:ellipsis` 生效；同时 `.el-tabs__content{overflow:hidden}` 会裁掉非 teleport 的 popper | 给下拉 `min-width:max(180px,100%)`；`.el-tabs__content` 改 `overflow:visible` |
| 3 | **记忆内容看不全**（客户点名） | `outcome` 被硬截断 150 字节（≈50 汉字）后**没有任何展开入口**；`decisions`/`next`/自定义字段在结果行里完全不显示 | `outcomePreview` 只做截断、不返回全文；`PayloadMeta` 只认 `task`/`status`/`outcome` | ① 预览层返回 `TextPreview{text, full, truncated}`；② 截断处渲染原生 `<details>…<pre>`「展开全文（N 字节）」；③ 结果行/下钻卡加**「详情」弹窗**，用 `payloadFields` 列出**全部**字段（每个长值各自可展开）；④ 全文经 `esc()` 转义（内容走 innerhtml 通道） |
| 4 | 类型表格右侧按钮被裁 | 「清空 / 删除」落到视口外（实测 row `scrollWidth` 1044 > `clientWidth` 943） | 列宽写死固定 px，总宽 980px 超出可用宽度 | 列宽改 `minmax(…,1fr)`，容器允许横向滚动 |
| 5 | 类型描述被硬裁 | 描述 `max-height:34px` 使 3 行只显示 1.5 行，末行被切一半 | `max-height` 裁行不等高 | 改 `-webkit-line-clamp:2`（整行截断），全文走「详情」弹窗 |
| 6 | 禁用塔层文案重复 | 未配置层连读「未配置未配置」 | 数值位与单位位都写「未配置」 | 数值位改占位符 `—`，单位位保留「未配置」 |
| 7 | **硬编码运行时信息** | 隔离实例上头部仍显示 `127.0.0.1:8900`、侧栏写死 `~/.chronolog` | 页面写死默认值，与实际配置（测试实例/容器映射）不符 | `buildUiApp` 注入真实 `cfg.addr:cfg.port` 与 `cfg.dir`；`buildUiApp`/`serveUi` 签名由 `host` 改为 `cfg` |
| 8 | 侧栏长路径折行挤压 | 绝对路径折成 3 行，行高由 24px 涨到 42px | 未做溢出处理 | 单行省略 + `title` 悬停显示完整路径 |
| 9 | 弹窗表单竖排一列 | 弹窗内「粒度链」7 个复选框挤在 101px 宽里竖排一行一个，标签右对齐、离控件很远 | 弹窗宽 560px 而部分 label 很长，行内 label 把 `__content` 挤到 101px；`text-align` 由 EP 的 `.el-form-item--label-right` 修饰类决定 | 弹窗内改「label 上置 + 控件全宽」，并对齐该修饰类特异性覆盖 |
| 10 | 统计卡被 `overflow:hidden` 裁切 | `.ui-stat` 装饰光斑触发溢出裁切 | 装饰元素未脱离布局影响 | `overflow:visible` + 光斑 `pointer-events:none` |
| 11 | 头部把 `0.0.0.0` 当访问地址 | 绑所有网卡时界面显示「服务 0.0.0.0:18901」，照此访问必然失败 | 第 7 条消除硬编码时，把 `cfg.addr`（**绑定**地址）直接拼成服务地址——绑定语义 ≠ 可达语义；`0.0.0.0` 是「所有网卡」的绑定通配，不是可访问目标 | 展示层按绑定语义渲染并标出可达范围：`0.0.0.0/::` → 局域网可达 · 所有网卡；`127.0.0.1/::1` → 本机可达 · 仅本机；具体网卡 → 指定地址可达 · `<addr>:<port>`。侧栏新增「监听」一行。逻辑落在 `chronomem.ui`（`listenDisplay`/`listenScope`/`listenBadgeText`）可独立单测 |

另外：`clampUtf8` / `clampUtf8*` 单测由 `chronomem.cli` 迁到 `chronomem.ui`（纯逻辑层），
删除重复的 `src/cli/ui_clamp_test.cj`。

> 关于第 11 条：服务端渲染拿不到请求 Host（cjxt 的 `ActionContext` 不暴露对端地址，
> `AppConfig` 也无内联脚本入口），因此**不猜客户端 IP**，只如实描述绑定语义与可达范围。

## 二、单测（TDD）

新增/迁移用例（`cjpm test` 168/168 全绿）：

- `chronomem.ui`：`clampUtf8` 边界（多字节、恰好等于 limit、limit≤0）、
  `payloadFields`（全字段/键升序/非标量/非法 JSON）、
  `normalizeInline`（换行制表符压缩、多字节安全）、
  `makePreview`/`previewOf`/`descPreview`（全文保留 + 截断标记）。
- `chronomem.cli`：长内容带「展开全文」入口且短文不套 `details`、
  详情弹窗列出全部 payload 字段、结果行有「详情」入口、
  `esc` 转义、禁用层不再出现「未配置未配置」、头部采用运行时信息、
  全文保留换行。

> 写实现时单测抓出两个自身缺陷：`normalizeInline` 段内多空格未压缩；
> `previewBlock` 的断言场景（TowerPage 未选桶时不渲染条目）不成立——已逐条修正。
